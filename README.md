# ISO 27001:2022 Cloud ISMS Gap Analysis

## Project Overview

This portfolio project presents a simulated cloud Information Security Management System (ISMS) gap analysis aligned with ISO/IEC 27001:2022. It demonstrates practical cloud compliance, risk assessment, control evaluation, evidence tracking, and remediation planning skills.

## Project Deliverables

The Excel workbook includes four worksheets:

- **Gap Analysis:** Evaluation of cloud security controls, implementation gaps, evidence, priorities, and recommendations.
- **Statement of Applicability:** Control applicability, justification, implementation status, ownership, and review dates.
- **Action Plan:** Prioritized remediation actions, responsible owners, deadlines, evidence requirements, and progress status.
- **Dashboard:** Visual summary of compliance status, priority risks, and remediation progress.

## Cloud Security Areas Covered

- Identity and Access Management
- User Account Lifecycle
- Multi-Factor Authentication
- Cloud Configuration Management
- Backup and Recovery
- Evidence Collection
- Risk Prioritization
- Remediation Tracking

## Key Findings

- 5 cloud security controls assessed
- 2 critical-priority gaps
- 2 high-priority gaps
- 1 medium-priority observation
- 20% implementation rate
- 5 remediation actions documented
